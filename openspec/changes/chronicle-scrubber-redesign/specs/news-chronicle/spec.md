# Spec Delta

## MODIFIED Requirements

### Requirement: CHRON-02 年単位の既読と安全な演出

年表は年全体を読み込めたページだけを既読にし、未表示の年を巻き込んではならない（MUST）。本人の年表は開いた時点で全年を読み込むため、読み込めた年はすべて既読になる。旧端末の既読は全項目を読んだ年だけ移す。世代の古い応答で最新既読を上書きしない。reduced-motionでは観測を止め、出現・拡大の演出はいずれも基底状態を読める状態（opacityを0にせず、文字を縮めない）にする。

#### Scenario: 一部だけ読んだ旧履歴

- **WHEN** 年の全項目を読んでいない
- **THEN** その年全体を既読へ移行しない

#### Scenario: 動きを減らす設定

- **WHEN** animation:noneが適用される
- **THEN** 節目が透明のまま残らず、年の数字と節目のタイトルも通常の大きさで読める

#### Scenario: 全年の読み込み

- **WHEN** 本人が年表を開き、全年のページを読み込めた
- **THEN** 読み込めた年はスクロールで表示したかに関わらず既読になる

#### Scenario: 途中の年で読み込みに失敗

- **WHEN** 古い年から順に読み込む途中でページの取得に失敗する
- **THEN** 読み込めた年だけを既読にし、失敗した年以降は未読のまま残す

## ADDED Requirements

### Requirement: CHRON-03 今から始まる全年表示

本人の年表は開いたときに全年のページを古い順に読み込み、読み込み終えたら最新の節目が見える位置（年表の末尾）を初期位置にしなければならない（MUST）。並び順はCHRON-01どおり古い順のままとする。読み込み中は読み込み中であることを示す。途中で取得に失敗した場合は、読み込めた年を表示したまま末尾に失敗と再試行の操作を出し、再試行では失敗した年から続きを読む。紹介ページのサンプルは初期スクロールを行わない。

#### Scenario: 数年分ある年表を開く

- **WHEN** 2024年から今年までの節目がある本人が年表を開く
- **THEN** 全年を読み込んだ後、今年の最後の節目が画面内に入った状態で表示される

#### Scenario: 途中の年で失敗

- **WHEN** 3年分のうち2年目の取得に失敗する
- **THEN** 1年目を表示したまま末尾に失敗と再試行を出し、再試行で2年目から読み直す

#### Scenario: 紹介ページのサンプル

- **WHEN** 紹介ページで年表のサンプルを表示する
- **THEN** ページのスクロール位置を年表の末尾へ動かさない

### Requirement: CHRON-04 年のスクラバー

本人の年表は2年以上の節目があるとき、画面右端に縦のスクラバーを常に表示しなければならない（MUST）。スクラバーは年の目盛りを年表内の位置に比例して並べ、現在のスクロール位置をつまみで示す。つまみのドラッグ、レールのクリック・タップで対応する位置へスクロールし、ドラッグ中はつまみの横にその位置の年を大きく示す。キーボードでは上下キーで前後の年へ、Home・Endで最初と最新の年へ移れ、支援技術には年を値とするスライダーとして伝える。1年分しかないとき、および紹介ページのサンプルでは表示しない。

#### Scenario: つまみを過去へ動かす

- **WHEN** 末尾にいる状態で、つまみを2024年の目盛りまでドラッグする
- **THEN** 年表が2024年の位置へスクロールし、ドラッグ中は「2024」が大きく示される

#### Scenario: 普通にスクロールする

- **WHEN** スクラバーを使わずに年表をスクロールする
- **THEN** つまみが現在位置に追従する

#### Scenario: キーボードで移動する

- **WHEN** スクラバーにフォーカスしてHomeキーを押す
- **THEN** 最初の年の見出しへ移り、スライダーの値が最初の年になる

#### Scenario: 1年分だけの年表

- **WHEN** 節目が今年の分しかない
- **THEN** スクラバーを表示しない

### Requirement: CHRON-05 スクロールに応じた強調

年表の年の数字と節目のタイトルは、画面の中央へ近づくほど大きく濃く、離れるほど小さく淡く表示しなければならない（MUST）。年の数字は画面端の0.55倍から中央の等倍（約1.8倍）、節目のタイトルは画面端の0.72倍から中央の等倍（約1.4倍）とし、日付・吹き出し・カード・ニュース・リンクの大きさは変えない。拡大で行の高さや周囲の配置を動かしてはならない。動きを減らす設定、またはscroll-driven animationに対応しないブラウザでは演出を行わず、通常の大きさの静的表示にする。

#### Scenario: 年の数字が中央を通る

- **WHEN** 年の見出しが画面下端から中央へスクロールしてくる
- **THEN** 数字が徐々に大きく濃くなり、中央を過ぎると小さく淡く戻る

#### Scenario: 長いタイトル

- **WHEN** 2行に折り返す節目のタイトルが中央で拡大される
- **THEN** 本文の幅からはみ出さず、下の吹き出しやカードの位置も動かない

#### Scenario: 非対応ブラウザ

- **WHEN** animation-timelineに対応しないブラウザで年表を開く
- **THEN** 年の数字と節目のタイトルを通常の大きさで静的に表示する
