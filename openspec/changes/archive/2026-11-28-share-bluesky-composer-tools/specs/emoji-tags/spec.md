# 絵文字・タグの差分仕様

## MODIFIED Requirements

### Requirement: EMOJI-02 カスタム検索と登録直後

カスタム絵文字を利用できる入力欄のサジェストはカスタム絵文字をUnicodeより先にし、本人PDSの未取り込み絵文字も名前一致で補わなければならない（MUST）。既存結果と重複させず、保存済み履歴はAppViewで再解決して削除済み・規格外だけを除く。

#### Scenario: 登録直後

- **WHEN** AppViewにまだ取り込まれていない本人絵文字を検索する
- **THEN** PDSキャッシュから補ってすぐ利用できる

#### Scenario: Blueskyへの返信・引用で絵文字を探す

- **WHEN** Blueskyへの返信・引用で絵文字パレット、全件ピッカー、または本文入力中の絵文字候補を使う
- **THEN** 候補はUnicode絵文字に限らなければならない（MUST）。検索はEMOJI-01に従い、お気に入りと最近の一覧には同じアカウントの既存データからUnicode絵文字を表示する。カスタム絵文字のお気に入りや履歴は保持する

### Requirement: TAG-01 正規形と表示用文字列

検索・ミュート・保存のタグは先頭#または＃を外した小文字へ正規化しなければならない（MUST）。プロフィール等の表示用原文ケースとは区別する。空・長過ぎ・空白入りを拒否し、重複は先着、満杯は元配列を保持する。最近タグは成功投稿の出現順で積む。

#### Scenario: 全角記号と大文字

- **WHEN** ＃Nagiを保存する
- **THEN** 正規形nagiを使うが表示原文の大文字を強制変更しない

#### Scenario: Blueskyへの投稿完了

- **WHEN** Blueskyへの返信・引用が全件作成される
- **THEN** 実際に送った本文のタグを出現順で、投稿したアカウントの端末内の最近タグに加えなければならない（MUST）。次回NagiとBlueskyの両方のパレットで表示する

#### Scenario: 投稿未完了

- **WHEN** Blueskyへの返信・引用の入力を取り消す、送信に失敗する、または分割投稿の一部だけが作られる
- **THEN** 最近タグを更新しない

### Requirement: TAG-02 タグパレットと文脈メニュー

パレットはお気に入りと最近を並べ、挿入時は#tagと後続空白を本文へ入れて入力に戻さなければならない（MUST）。本文タグの右クリック・長押しは画面1つのメニューでお気に入り・タブ・ミュート・一覧への操作を行う。長押し後のclickを抑制し誤遷移させない。

#### Scenario: iOS長押し

- **WHEN** contextmenuを出さないブラウザでタグを長押しする
- **THEN** 独自タイマーでメニューを開く

#### Scenario: パレット挿入

- **WHEN** タグを選ぶ
- **THEN** 本文へ挿入して入力欄へフォーカスを戻す

#### Scenario: Blueskyへの返信・引用でタグを挿入

- **WHEN** Blueskyへの返信・引用でタグパレットを開き、候補を選ぶ
- **THEN** 同じアカウントのNagi投稿欄で使うお気に入りと最近のタグを表示し、選んだタグを本文へ挿入して入力に戻さなければならない（MUST）
