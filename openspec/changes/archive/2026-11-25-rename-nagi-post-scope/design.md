# Design

## Context

投稿範囲モーダルと、通常投稿・ブログ・3行日記・インライン投稿の送信欄は、同じ範囲を表示辞書の別々のキーで表示している。「Blueskyにも」はすでにモーダルと送信欄で揃っている。 [提案](proposal.md)

## Decisions

- モーダルと送信欄の既存の表示キーに、言語ごとに同じラベルを設定する。返信時の案内は「投稿範囲で『Nagiに』を選んでください」のように、選択肢をそのまま参照する。英語は「Nagi」とする。
- 「Nagiに」は通常の届け先を示す。ブログは検索エンジンにも公開され、3行日記はTriLinesAtでも読めるため、各画面の補足で公開先を伝える。 [DIARY-05](../../../specs/diary-trilines/spec.md#diary-05)
- 内部では既存の範囲値を使い続ける。保存済みの選択や下書きは従来どおり解釈し、返信の制約はPOST-02に従う。 [POST-02](../../../specs/post-composer/spec.md#post-02)

## Risks / Trade-offs

選択肢名を使う操作テストは「Nagiに」で選ぶよう更新し、選択後の送信欄の表示も確認する。ロールバックは表示辞書とテストを元に戻すだけで行える。
