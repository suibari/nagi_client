# Spec Delta

## MODIFIED Requirements

### Requirement: PROFILE-05 ミュートとブックマーク

ミュートの除外はAppViewに任せ、クライアント状態は操作表示と設定に使わなければならない（MUST）。ミュートした作者とタグは、フィード・検索・通知に加えて、ブログ一覧とサイト内検索のブログ結果からも除き、ミュートした作者はゼンカツの回答一覧からも除く。作者のプロフィールと個別記事を本人が自分から開いた場合は隠さない。未ログイン向けに全員共通で生成する静的な一覧は、ミュートで変えない。例外として、ブログ一覧とゼンカツの回答一覧で、今のミュートを反映したAppViewの結果を表示できるまでの間（公開の結果を先に出している間、閲覧者付きの取得に失敗した場合を含む）は、クライアントのミュート一覧で作者とタグを仮に隠す。ミュート・解除の保存に成功したら、それ以前に読み込んだフィードを再び表示せず、取り直した結果を表示する。楽観切替は失敗で巻き戻す。ブックマークのフォルダ・検索・選択の意味はdesign.mdのbookmarks出典に従い、本人の状態を他アカウントと共有しない。

#### Scenario: ミュート一覧取得失敗

- **WHEN** 一覧が読めないがフィードは取得できる
- **THEN** クライアントの再フィルタで表示全体を止めない

#### Scenario: ミュートしてフィードへ戻る

- **WHEN** プロフィールで作者をミュートし、リロードせずにフィードへ戻る
- **THEN** その作者の投稿を含まない、取り直したフィードを表示する

#### Scenario: 表示中のフィードでタグをミュートする

- **WHEN** フィードの本文タグのメニューからタグをミュートする
- **THEN** 表示中のフィードを取り直し、そのタグを持つ投稿を隠す

#### Scenario: ミュートの保存に失敗する

- **WHEN** ミュートの保存がエラーになる
- **THEN** ボタンの表示を巻き戻し、読み込み済みのフィードはそのまま使う

#### Scenario: ブログ一覧

- **WHEN** ログインした利用者がブログ一覧を開く
- **THEN** ミュートした作者の記事と、ミュートしたタグを持つ記事を一覧と絞り込みタグに出さない

#### Scenario: ミュートした作者の記事を直接開く

- **WHEN** ミュートした作者の個別記事のURLを開く
- **THEN** 記事を表示する

#### Scenario: ゼンカツの回答一覧

- **WHEN** ログインした利用者がゼンカツの盤面を開く
- **THEN** ミュートした作者の回答を一覧に出さない

#### Scenario: 閲覧者付きの結果が届く前

- **WHEN** ログインした利用者のブログ一覧またはゼンカツの盤面に、閲覧者付きの結果より先に公開の結果が表示される
- **THEN** 手元のミュート一覧にある作者（ブログ一覧ではタグも）を仮に隠し、閲覧者付きの結果が届いたらそれをそのまま表示する

#### Scenario: 閲覧者付きの取得が権限不足で失敗する

- **WHEN** 古いセッションでブログ一覧の閲覧者付きの取得が拒否される
- **THEN** 公開の一覧を表示し、手元のミュート一覧で作者とタグを仮に隠す

#### Scenario: 未ログインの静的ページ

- **WHEN** 未ログインでブログ一覧を開く、またはsitemapを取得する
- **THEN** ミュートと無関係に、公開対象の記事をすべて含める
