# Design

## 確認中は折り畳み候補を縮めておく

**課題**：会話グループ形式でない項目（おすすめフィードなど）では、bot返信に人の返信が付いていないかを知るためにスレッドを取得する。確認が終わるまで展開して出すと、開くたびに展開から縮小へ表示が変わる。

**採用判断**：手元のデータで折り畳み候補と判定できたbot返信は、確認中も縮めて表示する。確認で残すべきと分かった返信と、確認に失敗した返信だけを展開する。

**理由と制約**：人の返信が付いたbot返信は少なく、縮小から展開へ変わる場面は確認が覆したときと失敗したときに限られる。失敗時に縮めたままにすると、人の返信が付いたbot返信を確かめないまま隠しうるため、FEED-05の「省略で返信の意図を消さない」考え方に合わせて展開する。セッション復元中（閲覧者が未確定）は、自分のルートを他人のものと誤判定しうるため従来どおり折り畳まない。
