# Spec Delta

## MODIFIED Requirements

### Requirement: POST-03 モードとモーダル状態

simple/rich/blogの本文はその場で装飾し、別のプレビュー欄を持たない必要がある（MUST）。simpleは装飾ボタンを畳む。diaryは別の3行入力を使い、simple/richだけをポストの同一グループにまとめる。返信・引用・ゲストの文脈ではblog/diaryを選ばせない。blogはモーダルではなく執筆ページ（BLOG-07）で書き、ポストのモーダルとComposerを共有しない。defaultScopeは初期値としてだけ扱う。ポストのモーダルは閉じても書きかけと進行中の動画送信を保持する。

#### Scenario: ポスト側で返信先を選ぶ

- **WHEN** 執筆ページでブログを書きかけたまま、別の画面でポストのモーダルから返信する
- **THEN** ブログ側へ返信・引用文脈を混入させない

#### Scenario: Android入力

- **WHEN** Samsungキーボード等の環境で書く
- **THEN** 互換用のtextarea経路を使い、記事内の重ね表示は一覧表示に戻す

### Requirement: POST-08 投稿おたすけの非干渉

おたすけは書き進め中は具体的な良さ、未入力・削除時は本人の過去投稿や日記を材料に声をかけなければならない（MUST）。IME変換中は新規生成だけを止め、既存の吹き出しを跳ねさせない。×を押したら、ポストではモーダルを閉じるまで、ブログでは執筆ページを離れるまで再表示しない。古い本文への応答は捨て、生成失敗では静かに消える。おたすけは入力欄を覆ってはならない。ブログの執筆ページでは、PC幅は記事メタ欄の下に置き、スマホ幅は下部に出してその高さの分だけページ下に余白を確保する。

#### Scenario: 生成中の追加入力

- **WHEN** 応答前に本文を書き進める
- **THEN** 古い本文への生成結果を表示しない

#### Scenario: おたすけを押す

- **WHEN** ソフトウェアキーボードで入力中に操作する
- **THEN** 入力欄からフォーカスを奪わない

#### Scenario: PC幅でブログを書く

- **WHEN** 広い画面の執筆ページでおたすけが声をかける
- **THEN** 吹き出しは右カラムの記事メタ欄の下に出て、本文欄と重ならない

#### Scenario: スマホ幅でブログを書く

- **WHEN** 狭い画面の執筆ページで、本文の末尾を書いているときにおたすけが出る
- **THEN** 吹き出しの高さの分だけページ下に余白ができ、本文の末尾までスクロールして見える
