# Spec Delta

## ADDED Requirements

### Requirement: BLOG-07 執筆・編集ページ

ブログの新規作成と編集は、同じ執筆ページで行わなければならない（MUST）。新規は `/write`、本人の記事の編集は `/write/<rkey>` とする。編集の対象は本人の `site.standard.document` だけとする。新規作成と同じUIで、タイトル・ヘッダー画像・タグ・本文・画像を変更できる。記事ページとフィード上の記事にある編集操作は、その場で編集せずこのページへ移動する。保存が済んだら記事ページへ移動し、AppViewが取り込むまでは保存した内容を表示する。未保存の変更があるままページを離れる操作には確認を出す。

#### Scenario: 未サインインで開く

- **WHEN** サインインしていない利用者が `/write` または `/write/<rkey>` を開く
- **THEN** ログイン画面へ移動する

#### Scenario: 他人や記事でないものを編集しようとする

- **WHEN** `/write/<rkey>` のrkeyに本人の `site.standard.document` が無い
- **THEN** 編集画面を出さず、記事が見つからないことを伝える。通常投稿を記事として公開しない

#### Scenario: 編集でタグを変える

- **WHEN** 記事を編集し、記事メタ欄でタグを足したり外したりして保存する
- **THEN** documentのtagsを、本文のハッシュタグと記事メタ欄のタグを合わせたものに置き換える

#### Scenario: 保存直後の記事ページ

- **WHEN** 保存して記事ページへ移動したが、AppViewがまだ新しい内容を返さない
- **THEN** 保存した本文・タイトル・画像を表示し、取り込みが済んだらAppViewの内容に切り替える

#### Scenario: 書きかけで離れる

- **WHEN** 未保存の変更がある状態で、リンクの移動・ブラウザの戻る・タブを閉じる操作をする
- **THEN** 離れてよいか確認し、取り消したら書きかけをそのまま残す。保存の完了による移動では確認しない

#### Scenario: 編集では下書きを使わない

- **WHEN** 既存の記事を編集している
- **THEN** 下書きの自動保存と下書き一覧を出さない。下書きは新規作成のときだけ扱う

## MODIFIED Requirements

### Requirement: BLOG-03 編集・削除の追従と非公開保持

既存記事はrkeyで対応させて編集・削除し、記事でない投稿を編集だけで公開してはならない（MUST）。本文に見出しが無ければ既存タイトルを残す。タグを指定しない更新は既存タグの保持を意味し、執筆ページで記事メタ欄から保存した場合だけタグを置き換える。site/publishedAt/未知フィールドを保持する。全削除はNagiに属するpublication/documentだけを対象にする。

#### Scenario: 通常投稿の編集

- **WHEN** documentが存在しない
- **THEN** 新規記事を作らない

#### Scenario: 本文だけの編集

- **WHEN** タグ指定なしで更新する
- **THEN** 記事メタ欄で設定したタグを消さない

#### Scenario: 執筆ページからの保存

- **WHEN** 執筆ページで記事メタ欄のタグを空にして保存する
- **THEN** 本文のハッシュタグ以外のタグを外す
