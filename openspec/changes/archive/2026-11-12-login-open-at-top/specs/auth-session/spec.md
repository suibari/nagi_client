# Spec Delta

## ADDED Requirements

### Requirement: AUTH-07 ログイン画面の初期表示

ログイン画面は、どの入口から開いても先頭から表示しなければならない（MUST）。ランディングと参加の締めの参加ボタンは、新規登録の節へ自動でスクロールする移動先を使ってはならない。既存アカウントのハンドル入力とログインボタンを、新規登録の節より先に見せる。

#### Scenario: ランディングの参加ボタンから開く

- **WHEN** スマホ幅でランディングの「Nagiをはじめる」を押す
- **THEN** ログイン画面が先頭から表示され、ハンドル入力とログインボタンが最初の画面に見える

#### Scenario: 古いアンカー付きURLから開く

- **WHEN** `/login#signup` を開く
- **THEN** 新規登録の節へスクロールせず、先頭から表示する
