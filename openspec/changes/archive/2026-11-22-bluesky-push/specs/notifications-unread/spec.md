# Spec Delta

## ADDED Requirements

### Requirement: NOTIFY-08 Blueskyの通知のPushと設定

Bluesky連携を有効にした利用者は、Blueskyの返信・メンション・引用・いいね・リポスト・フォローをWeb Pushで受け取れなければならない（MUST）。初期状態はオフで、利用者が通知設定で有効にしたときだけ配信する。種類ごとにオン・オフでき、Nagiの通知の設定（NOTIFY-01、未設定は有効）とは別に保存する。配信は操作1件ごとに行い、まとめたり件数を出したりしてはならない（MUST NOT）。端末の購読はNagiの通知と共用し（NOTIFY-03）、通知を開くとBlueskyの通知タブまたは対象のスレッドへ移動する。

#### Scenario: 初期状態

- **WHEN** Bluesky連携を有効にしただけで、Pushの設定を変えていない
- **THEN** BlueskyのPushを配信しない

#### Scenario: いいねが続く

- **WHEN** Pushを有効にした利用者の投稿に、短い間に3人がいいねする
- **THEN** 3件を個別に配信し、「ほか2人」のような件数の表現を使わない

#### Scenario: 種類ごとの設定

- **WHEN** いいねだけをオフにしている
- **THEN** いいねでは配信せず、返信などは配信する

#### Scenario: 通知を開く

- **WHEN** Blueskyの返信のPushを開く
- **THEN** Nagiを開き、対象のBlueskyスレッドへ移動する

### Requirement: NOTIFY-09 BlueskyのPushの文面と除外

BlueskyのPushの文面はNagiの通知と同じく、相手の表示名と、返信・メンション・引用ではその本文、いいね・リポストでは対象投稿の文を入れなければならない（MUST）。Nagiで成人確認できない利用者には、成人向けのラベルが付いた投稿の本文を入れない（BSKY-02）。自分自身の操作では配信しない。ブロックした相手・ブロックされた相手からの操作は、公開されたブロックの関係を確認して配信せず、確認できないときも配信しない。Bluesky側のミュート・スレッドのミュート・ワードミュートは判定に反映しない。これらは本人の認証なしにサーバーから取得できない情報であり、2026-11-21に制約として許容した。

#### Scenario: 成人向けの返信

- **WHEN** 成人確認できない利用者に、成人向けのラベルが付いた返信が届く
- **THEN** 本文を入れずに、返信があったことだけを配信する

#### Scenario: ブロックした相手

- **WHEN** Blueskyでブロックしている相手、またはブロックされている相手がいいねする
- **THEN** Pushを配信しない

#### Scenario: ブロックの確認に失敗

- **WHEN** ブロックの関係の問い合わせが失敗する
- **THEN** Pushを配信しない

#### Scenario: ミュートした相手

- **WHEN** Blueskyでミュートしている相手が返信する
- **THEN** Pushは配信される。通知タブの一覧ではBluesky側の判定により表示されない
