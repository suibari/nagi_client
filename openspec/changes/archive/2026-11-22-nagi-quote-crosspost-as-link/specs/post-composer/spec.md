# Spec Delta

## MODIFIED Requirements

### Requirement: POST-07 引用URLの取り扱い

通常モードでは文字列全体が内部スレッドURLのときだけ引用スロットに取り込み、本文へURLを残さない必要がある（MUST）。文章中のURLと画像ペーストを奪わない。引用可能なのは本人またはAppViewがisBotを付けた投稿とする。引用できない投稿のURLを単独で貼った場合は、URLをリンクとして本文に残す。他人のNagi投稿のURLは、単独で貼った場合も文中に書いた場合もリンクカードにしてはならない（MUST NOT）。相手の本文を自分の投稿の中に見せないためである。この制限はblogとBluesky専用の入力欄にも適用する。引用できない投稿のURLを残すときに案内は出さない。blogではURLを本文に残して通常のリンクカードにする（他人のNagi投稿を除く）。

#### Scenario: 文章とURLの混在

- **WHEN** スレッドURLを含む文章を貼る
- **THEN** 文章全体を引用として吸い上げない

#### Scenario: 引用取得失敗

- **WHEN** 引用URL単独を貼って取得に失敗する
- **THEN** 本文へ勝手にURLを戻さず、理由を出して貼り直しを選べるようにする

#### Scenario: 他人の投稿のURLを単独で貼る

- **WHEN** 本人でもbotたんでもない人の投稿のURLだけを貼る
- **THEN** 引用にせず、URLをリンクとして本文に残し、リンクカードを付けない

#### Scenario: 文中の他人の投稿のURL

- **WHEN** 本人でもbotたんでもない人の投稿のURLを文章の中に書く
- **THEN** リンクにするが、リンクカードを付けない

#### Scenario: ブログに他人の投稿のURLを書く

- **WHEN** blogの本文に、本人でもbotたんでもない人の投稿のURLだけの行を置く
- **THEN** リンクにするが、リンクカードを付けない
