# Spec Delta

## MODIFIED Requirements

### Requirement: BSKY-04 クロスポストの可否

外部連携はオプトイン・実際の権限・対象の存在を確認しなければならない（MUST）。kossoriと本文CWは送信しない。メディアCWはBlueskyがぼかすself-labelがある場合だけ許可する。Nagi投稿の返信ボタンから開く共通Composerでは、本人のクロスポスト済み投稿の既存コピーを1つ参照できる場合にBlueskyへ続けられる。引用付きの投稿は、引用先がこっそり投稿でなければBlueskyへ出せ、引用の扱いはBSKY-05に従う。対象はNagi投稿・ニュース・ラジオの引用とする。返信と引用の同時外部化は許可しない。Bluesky投稿への返信・引用はこの判定の対象外で、BSKY-09に従う。

#### Scenario: コピー削除済み

- **WHEN** 自分のクロスポストへの返信を外部にも出そうとする
- **THEN** 孤立した返信を作らず送信を止める

#### Scenario: メディアCWのみ

- **WHEN** 対応ラベルが無い画像を外部へ出そうとする
- **THEN** ぼかしが失われるのでブロックする

#### Scenario: クロスポストしていない投稿の引用

- **WHEN** 自分のクロスポストしていない投稿やbotたんの投稿を引用し、Blueskyにも出す
- **THEN** クロスポストを選べ、Bluesky側では引用先をリンクとして出す

#### Scenario: こっそり投稿の引用

- **WHEN** 自分のこっそり投稿を引用した投稿をBlueskyにも出そうとする
- **THEN** Bluesky上では開けないリンクになるので、クロスポストを選べない

#### Scenario: ニュースの引用

- **WHEN** ニュースを引用した投稿をBlueskyにも出す
- **THEN** クロスポストを選べ、Bluesky側ではNagiのニュースページをリンクとして出す

### Requirement: BSKY-05 分割と埋め込み

本文は300graphemesかつ3000bytes以内へ分割し、改行→空白→grapheme境界を優先しなければならない（MUST）。可能な限りURL・mention facetをまたがず、分割先のbyte位置を直す。画像と動画の混在はBlueskyでは動画だけにする。via=Nagiで外部botの二重返信を避ける。

引用付きの投稿は、引用先が本人のクロスポスト済み投稿でコピーを参照できる場合はコピーの引用にする。それ以外は引用先の公開URLのリンクカードにする（MUST）。リンク先は、Nagi投稿ならスレッドページ、ニュースならNagiのニュースページ、ラジオなら曲ページとする。画像・動画もある場合はメディアを埋め込み、引用先のURLを本文の末尾にリンクとして入れる。引用のカードは本文のリンクカードより優先する。他人のNagi投稿のURLは、本文にあってもリンクカードにしてはならない（MUST NOT、POST-07）。

#### Scenario: 長い日本語投稿

- **WHEN** Nagiの本文がBluesky上限を超える
- **THEN** byte数とgrapheme数の両方を守るスレッドを作る

#### Scenario: 巨大facet

- **WHEN** facetを避けると分割できない
- **THEN** 必要な箇所だけfacetを諦めて強制分割する

#### Scenario: コピーのある投稿の引用

- **WHEN** 自分のクロスポスト済み投稿を引用し、コピーを参照できる
- **THEN** Bluesky側ではコピーの引用にする

#### Scenario: コピーの無い投稿の引用

- **WHEN** 引用先にBlueskyのコピーが無い、またはコピーを参照できない
- **THEN** 引用先のスレッドページのリンクカードにする

#### Scenario: 画像付きの引用

- **WHEN** 画像を添付し、コピーの無い投稿を引用してBlueskyにも出す
- **THEN** 画像を埋め込み、引用先のURLを本文の末尾にリンクとして入れる

#### Scenario: 本文に他人の投稿のリンクがある

- **WHEN** 他人のNagi投稿のURLを本文に書いてBlueskyにも出す
- **THEN** リンクの文字だけを出し、リンクカードを付けない
