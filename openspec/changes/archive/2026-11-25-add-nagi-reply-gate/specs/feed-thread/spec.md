# Spec Delta

## ADDED Requirements

### Requirement: FEED-11 返信を受け付けない投稿

閲覧者が返信できない投稿には、Nagiの返信ボタンを出してはならない（MUST NOT）。代わりに、返信を受け付けていないことを示す。返信できるかどうかはAppViewが返す値に従い、クライアントで判定しない。投稿者本人には常に返信ボタンを出す。

#### Scenario: 返信不可の投稿を他人が見る

- **WHEN** 「返信不可」で投稿された他人の投稿を表示する
- **THEN** 返信ボタンを出さず、返信を受け付けていないことを示す

#### Scenario: 自分の制限付き投稿

- **WHEN** 自分が「返信不可」で投稿した投稿を表示する
- **THEN** 返信ボタンを出し、続けて返信できる
