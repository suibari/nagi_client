# Spec Delta

## MODIFIED Requirements

### Requirement: CARD-02 日付境界・報酬・再試行

通常の取得・ゼンカツはJST4時をプレイ日境界とし、nextDrawAt等のサーバ状態に従って再取得しなければならない（MUST）。カードを引けるのは通常枠の1日1枚とし、リアクションで追加のカードを引く枠を持たない。記念日報酬は通常枠と区別し、抽選枠を消費しない。記念日報酬はログイン時に受け取り1枚ずつキューで表示する。

#### Scenario: 連続リアクション

- **WHEN** 通常枠のカードを引いた日に、他人の投稿やニュースへ続けてリアクションする
- **THEN** カードの取得や取得の案内を出さず、次に引ける時刻は通常枠の次の日付境界のままである

#### Scenario: 複数の記念日

- **WHEN** 同日に記念日カードを複数受け取る
- **THEN** モーダルを重ねず閉じるたび次へ進む

#### Scenario: リアクション枠で引いた過去のカード

- **WHEN** 廃止前にリアクション枠で引いたカードを図鑑や記録で開く
- **THEN** 所持と記録をそのまま表示する

### Requirement: CARD-07 おすそわけと数の反映

だぶりの提供でƵを受け取り、未所持カードを受け取る操作はAppView確定値に従わなければならない（MUST）。ボードに置かれたAARが無いときは、botたんのAARを300Ƶで受け取れる。置かれたAARがあればそちらを優先し、通常のAARの価格で受け取る。複数提供の演出では1枚ずつ飛ばし、到着した時点で対応するƵ表示を増やす。

#### Scenario: 複数枚の提供

- **WHEN** サーバが受理した複数カードを演出する
- **THEN** 一括の数字飛びだけで終えず枚ごとの到着に合わせる

#### Scenario: botたんのAAR

- **WHEN** ボードに置かれたAARが無く、AARを持っていない人がボードを開く
- **THEN** AARを「ある」として300Ƶで表示し、ヘルプにも同じ額を示す
