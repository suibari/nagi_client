# Spec Delta

## ADDED Requirements

### Requirement: CARD-09 パック開封の取得演出

抽選で新しく引いたカード（通常の1日1枚、ゲストのドロー）は、封をしたパックとして先に表示し、利用者が開封してから取り出さなければならない（MUST）。開封はパック上端の切り取り線を横になぞる操作で行い、なぞった分だけ封が破れる。タップ・クリック・Enter・Spaceでも開封できる。パックの表にはゼンカツのロゴとbotたんを描く。パックは開封されるまで待ち、自動では開かない。パックの見た目と振動はレア度によって変えてはならない。開封後は裏向きのカードがパックから出て、CARD-04のレア度演出を経て自動で表にめくれる。記念日カード、同日の再取得、閲覧、おすそわけでの受け取りではパックを出さない。動きを減らす設定では、パックを出さず最初から表を見せる。開封前は背景クリックで閉じず、Escキーとスキップで抜けられる。

#### Scenario: なぞって開ける

- **WHEN** 新しく引いたカードのパックで、切り取り線を幅の6割以上なぞって離す
- **THEN** 残りの封が破れ、裏向きのカードが出てきて、レア度演出のあと表にめくれる

#### Scenario: なぞりが足りない

- **WHEN** 切り取り線を少しだけなぞって離す
- **THEN** 封は開かず、パックのまま待つ

#### Scenario: タップで開ける

- **WHEN** パックをタップする、またはフォーカスしてEnterを押す
- **THEN** 破れるアニメーションが自動で再生され、なぞった場合と同じ流れに進む

#### Scenario: パックからレア度が分からない

- **WHEN** NとAARのカードをそれぞれ引く
- **THEN** 開封前のパックの見た目と振動は同じで、昇格色・振動・暗転はカードが出てから始まる

#### Scenario: パックの段階でスキップ

- **WHEN** 開封前に「演出をスキップ」を押す
- **THEN** すぐ表を見せ、紙吹雪を出さない

#### Scenario: 記念日カード

- **WHEN** ページ表示時に記念日カードの受け取りダイアログが開く
- **THEN** パックを出さず、現行どおりレア度演出のあと表にめくれる

#### Scenario: 当日分を見返す

- **WHEN** 同日にもう一度ドローの入口を押す（alreadyDrawn）
- **THEN** パックを出さず、最初から表を見せる

#### Scenario: 開封前に背景をクリック

- **WHEN** パックの段階で背景をクリックする
- **THEN** ダイアログを閉じない

#### Scenario: 動きを減らす設定

- **WHEN** prefers-reduced-motion が有効な状態で新しいカードを引く
- **THEN** パックを出さず最初から表を見せる
