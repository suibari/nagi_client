# Spec Delta

## ADDED Requirements

### Requirement: FEED-12 公開投稿詳細からの参加

クライアントは、認証状態の確認後、未ログインの閲覧者が取得できた公開投稿の詳細に、投稿と返信に続けてNagiの紹介を1つ表示しなければならない（MUST）。紹介はニュース・ブログの個別ページと共通とし、参加ボタンで既存のログイン・アカウント作成画面を開く。

#### Scenario: 未ログインで公開投稿を直接開く

- **WHEN** 未ログインの閲覧者が共有された公開投稿詳細のURLを開く
- **THEN** 投稿と返信を読め、会話の後ろにNagiの紹介と参加ボタンが表示される
- **AND** 参加ボタンから `/login` を開き、既存のログインとアカウント作成を選べる

#### Scenario: サインイン済みで公開投稿を直接開く

- **WHEN** サインイン済みの閲覧者が公開投稿詳細を開く
- **THEN** 認証の復元中と復元後のいずれも紹介を表示せず、既存の会話表示と操作を利用できる

#### Scenario: 公開投稿を確認できない

- **WHEN** 投稿が読み込み中、取得できない、こっそり、削除済み、または利用できない状態である
- **THEN** 紹介を表示せず、それぞれの既存の表示を保つ
