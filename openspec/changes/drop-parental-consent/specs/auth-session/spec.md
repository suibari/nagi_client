# Spec Delta

## MODIFIED Requirements

### Requirement: AUTH-07 ログイン画面の初期表示

ログイン画面は、どの入口から開いても先頭から表示しなければならない（MUST）。ランディングと参加の締めの参加ボタンは、新規登録の節へ自動でスクロールする移動先を使ってはならない。既存アカウントのハンドル入力とログインボタンを、新規登録のボタンより先に置く。スマホ幅でも、ログインボタンと新規登録ボタンの両方を最初の画面に収める。新規登録ボタンの文言はアカウントを作る操作であることを明示し、ランディングと参加の締めの参加ボタンと同じ文言にしてはならない。Bluesky連携のスイッチは両方のボタンより上に置き、どちらから進んでも同じように効く。両方のボタンの下には利用規約とプライバシーポリシーへの同意の文を置き、年齢の告知は置かない。

#### Scenario: ランディングの参加ボタンから開く

- **WHEN** スマホ幅でランディングの「Nagiをはじめる」を押す
- **THEN** ログイン画面が先頭から表示され、ハンドル入力・ログインボタン・新規登録ボタンが最初の画面に見える

#### Scenario: 古いアンカー付きURLから開く

- **WHEN** `/login#signup` を開く
- **THEN** 新規登録の節へスクロールせず、先頭から表示する

#### Scenario: 新規登録ボタンの文言

- **WHEN** ログイン画面を表示する
- **THEN** 新規登録ボタンは「アカウントを作ってはじめる」（英語表示では同等の文言）と表示され、「Nagiをはじめる」とは表示されない

#### Scenario: 連携をONにして新規登録へ進む

- **WHEN** Bluesky連携のスイッチをONにして新規登録ボタンを押す
- **THEN** ログインボタンを押した場合と同じく、連携の権限を含めて認可を始める

#### Scenario: 同意の文

- **WHEN** ログイン画面を表示する
- **THEN** 利用規約とプライバシーポリシーへのリンクを含む同意の文が表示され、保護者の同意についての告知は表示されない
