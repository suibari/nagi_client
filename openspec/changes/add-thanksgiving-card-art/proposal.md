# Proposal

## Why

サンクスギビングデーは既に記念日カードの配布対象だが、カード定義にイラストの指定がない。用意した WebP をカード面に表示し、記念日の受け取りや所持カード一覧で見られるようにする。

## What Changes

- サンクスギビングデーの記念日カードの受け取り画面と所持カード一覧に、透過のイラストを表示する。
- 既存の透過線画と同じテーマ処理を適用し、ライト・ダーク双方でイラストが見えるようにする。
- 配布日、対象アカウント、カード番号、通常ドロー枠の扱いは今回の対象外とする。

## Capabilities

### New Capabilities

### Modified Capabilities

- `cards-zenkatsu` — CARD-02 の記念日カードについて、サンクスギビングデーのカード面とテーマごとの背景表示を定める。

## Impact

Nagi Web のカード用静的アセットおよび線画の判定と、別リポジトリにある AppView の記念日カード定義が対象。既存の `art` フィールドを利用する。
