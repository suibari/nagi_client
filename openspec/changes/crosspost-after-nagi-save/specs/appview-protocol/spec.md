# Spec Delta

## ADDED Requirements

### Requirement: API-09 表示内容が変わらない更新は編集としない

AppViewは、公開投稿の更新のうち利用者に見える内容（本文・facets・embed・リンクカード・言語・CW・ラベル・記事の見出し等）が変わらないものを編集とみなしてはならない（MUST）。この更新では編集済みの表示、翻訳、bot判定、通知をやり直さず、付帯情報だけを最新のレコードへ反映する。見える内容が1つでも変わる更新は従来どおり編集として扱う。クライアントはこの契約を前提に、作成直後の投稿へクロスポスト参照等の付帯情報を追記できる。

#### Scenario: クロスポスト参照だけの追記

- **WHEN** 作成直後の公開投稿に、Blueskyコピーへの参照だけを追記する更新が取り込まれる
- **THEN** 投稿は編集済みにならず、翻訳・bot判定・通知も再実行されず、参照だけが表示用データに反映される

#### Scenario: 本文の変更を含む更新

- **WHEN** 付帯情報の追記と同時に本文も変わる更新が取り込まれる
- **THEN** 従来どおり編集として扱い、編集済みの表示と翻訳等の再実行を行う

#### Scenario: AppViewが未対応の環境

- **WHEN** AppViewがこの契約にまだ対応していない
- **THEN** クライアントは参照追記による順序変更を有効にしてはならず、従来の判定のまま編集扱いされる経路を本番に出さない
