# 季節イベント

## Purpose

### 機能概要

季節や暦の節目に合わせた催しを通して、利用者がNagiでその時期ならではの体験を楽しめるようにする機能カテゴリである。アドベントカレンダーを実装済みイベントとして扱い、今後追加予定のおみくじなどもこのカテゴリへ含める。

カテゴリの対象は季節イベント全般であり、アドカレ固有の開催期間・日付境界・開封の仕組みを、すべてのイベントに共通する仕様とはしない。新しいイベントを加える際は、目的・利用の流れ・期間・保存する状態などを、そのイベントの要件として定義する。

### 機能一覧

| 機能                             | 状況     | 役割・利用者ができること                                           | 詳細要件                |
| -------------------------------- | -------- | ------------------------------------------------------------------ | ----------------------- |
| アドベントカレンダー（アドカレ） | 実装済み | 公開日ごとにカード・手紙を開き、既読・開封状態を端末間で引き継ぐ。 | [SEASON-01](#season-01) |
| おみくじ                         | 追加予定 | 季節イベントとしてこのカテゴリに含める。体験の詳細は今後定義する。 | 未定義                  |

### 主な利用の流れ

実装済みのアドベントカレンダーでは、次の流れになる。

1. 開催・案内期間に表示される入口からカレンダーを開く。
2. 公開済みの日のカードと手紙を読む。未来の日の内容は表示しない。
3. 本人の既読・開封状態を確認して開封演出を行い、見終えた状態を保存する。
4. 別の端末から開いた場合も、同期した状態に従って表示する。

おみくじの提供時期、操作、結果、再実行、保存・共有の扱いは未定義であり、現行の動作としては扱わない。

## Requirements

イベントごとに開催期間・日付境界・状態の扱いを定義する。現在の詳細要件はアドベントカレンダーを対象とする。

<a id="season-01"></a>

### Requirement: SEASON-01 アドベントの暦と既読

アドベントはJST0時境界で12月1〜25日を公開し、メニュー表示は12月1日から1月7日いっぱい、1月の参照年は前年でなければならない（MUST）。カードの4時境界を流用しない。既読・開封はpreferencesで同期し、サーバ既読取得前に開封を再演しない。未公開の中身を先回りURLで出さない。

#### Scenario: 1月の閲覧

- **WHEN** 1月5日にメニューを開く
- **THEN** 前年12月のカレンダーを指す

#### Scenario: 別端末で開封済み

- **WHEN** 本人の既読をまだ取得できない
- **THEN** 未開封と決めつけて再演しない
