# botたんラジオ

## Purpose

### 機能概要

利用者に向けた曲とbotたんのDJコメントを受け取り、過去の放送もジャケットの棚から振り返れる機能である。長いコメントを一覧へ並べず、選んだ1曲をブースで読む体験にする。気に入った回を引用投稿したり、曲のページを共有したりできる。

選曲・コメント生成・放送の保存は外部のAppViewやbotの責務であり、この仕様は取得・表示・引用時の公開レコード・共有を扱う。

### 機能一覧

| 機能                 | 役割・利用者ができること                               | 詳細要件                                      |
| -------------------- | ------------------------------------------------------ | --------------------------------------------- |
| 最新放送の取得       | 起動・ログイン・復帰時に最新状態を読む。               | [RADIO-01](#radio-01)                         |
| DJブースと履歴棚     | 最新曲を初期選択し、hover・focus・クリックで曲を選ぶ。 | [RADIO-02](#radio-02)                         |
| ジャケット代替と日付 | 画像が無い曲も識別でき、JSTの放送日でまとめる。        | [RADIO-02](#radio-02)                         |
| 放送の引用           | 送信時に権限を確認して本人repoへ公開レコードを書く。   | [RADIO-01](#radio-01) / [RADIO-03](#radio-03) |
| 曲ページの共有       | 共有シートまたはクリップボードで曲を知らせる。         | [RADIO-04](#radio-04)                         |

### 主な利用の流れ

1. 最新放送または履歴を開く。最初は最新曲のDJコメントを表示する。
2. 棚のジャケットにhover・focusして一時的に内容を見て、クリックで選択を固定する。
3. 引用する場合は投稿モーダルで内容を書き、送信時に放送の公開参照を作る。
4. 共有はOSの共有シートを開き、使えない環境ではURLをコピーする。

この文書は現行クライアントの振る舞いを整理する。設計判断は [design.md](design.md)、導入時の証跡は [コメント原文](../../reference/comment-snapshot/radio.md)、既知の不整合は [known-gaps.md](../../known-gaps.md) に分けて記録する。シナリオは確認条件であり、全外部環境での実行合格を示すものではない。

## Requirements

<a id="radio-01"></a>

### Requirement: RADIO-01 取得と公開データの境界

ラジオは起動・ログイン・画面復帰に取得し、開きっぱなしで定期取得を行わない必要がある（MUST）。公開レコードは引用投稿の送信時に作り、モーダルを開いただけでは作らない。同じ回には同じrkeyを使う。

#### Scenario: 投稿キャンセル

- **WHEN** ラジオの引用を開いて閉じる
- **THEN** 本人repoへ不要な公開レコードを残さない

#### Scenario: 同じ回を再引用

- **WHEN** 別の投稿から同じ放送を引用する
- **THEN** 公開ラジオレコードを別々に増やさない

<a id="radio-02"></a>

### Requirement: RADIO-02 ブースと棚の状態

DJコメントはブースの1か所だけに出し、初期選択を最新曲としなければならない（MUST）。棚のhover/focusは一時選択、クリックは固定、離脱時は固定曲に戻す。日付束ねは放送と同じJSTを使う。ジャケット無しは曲名から決まる色で代替し、画像は切り抜かない。

#### Scenario: 試聴の解除

- **WHEN** 固定曲以外へhoverしてから離れる
- **THEN** 固定中の曲のコメントへ戻る

#### Scenario: 長いコメント

- **WHEN** DJ文がブース高さを超える
- **THEN** ブース全体で画面を覆わず内部でスクロールする

<a id="radio-03"></a>

### Requirement: RADIO-03 引用権限と旧履歴

ラジオ引用に必要なrepo権限が無ければ投稿前に再認可を案内しなければならない（MUST）。曲カードは新形式の曲ページと旧YouTube履歴の両方を扱う。DJコメントは現在表示している言語を使う。

#### Scenario: 旧セッション

- **WHEN** ラジオrepo権限が無い
- **THEN** 既存機能を止めず引用投稿時に再認可を出す

<a id="radio-04"></a>

### Requirement: RADIO-04 共有の結果

曲ページ共有はWeb Shareを優先し、無ければクリップボードへコピーしなければならない（MUST）。コピー完了だけをtrue、共有シートのキャンセルをfalseとし、その他の失敗を伝える。

#### Scenario: 共有シートを閉じる

- **WHEN** 投稿せずにキャンセルする
- **THEN** コピーしましたという成功表示を出さない
